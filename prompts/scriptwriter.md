<!--
  ↑ 角色句。8B 级本地模型对「你是谁」很敏感：这一句决定它按「教科书摘要」

请从下面【正文】提炼最多 {{max_n}} 句口语化、能独立听懂的短句，每句严格 ≤20 字（像朋友聊天，不要书面长句）。
<!--
  ·「最多 {{max_n}} 句」：来自 config `limits.max_sentences`（默认 12）。
    12 的来历是产出时长——成片实测落在 23–39s 区间（口径见 demo/README 的数字口径表），
    对短视频完播友好。改这个数请同步想清楚目标时长。
  ·「严格 ≤20 字」：卡片正文一行的物理容量 + 口播节奏。实测超 20 字会换行、视觉密度上升。
  ·「能独立听懂」：观众是滑到的，不是从头看的 —— 每句必须脱离上下文成立。
  ·「像朋友聊天，不要书面长句」：这句是**反 AI 味**的必要条件。
    不写它，模型会输出「综上所述」式的表达，卡片上会很像说明书。
-->
每句配两个标签：
<!--
  ↑ 两个标签是刻意的「一分为二」：标题要像人话（给人读），图标要机器可判（给代码用）。
    合成一个字段会两头不讨好——两边的理由见各自注释。这是错题库 L-01 的直接产物。
-->
  keyword：2-4 字，做画面大标题，自由发挥、要有信息量（如「定义」「心态」「先立规矩」）
<!--
  ↑ keyword **故意不给清单**，让模型自由生成。反直觉，但实证如此：
    标题是给人读的，自由生成才有人味（「先立规矩」这种词不会出现在任何预设词表里）。
    代价是同一批卡片标题字长不一 —— 可接受，卡片排版按字数自适应。
    ⚠️ 千万不要把 keyword 也做成受控清单：那会让标题退化成"标签腔"。
-->
  concept：画面图标的语义标签，**必须从上表选一个最贴近的**，不要自造新词
<!--
  ↑ concept **必须受控**，是全链路最硬的一条约束。它来自实测病灶：
    自由生成的 concept 说的是「叙事概念」（定义/心态/观察…），而本地图标词表是按
    「AI/工程化主题词」建的 → 两者交集极小 → 匹配全落空 → 退到散列兜底
    → 12 张卡散进 16 个中性图形 → 实测「表达/应用/改变」三张同为拼图、菱形撞 2 次。
    药方不是补字典，而是把 concept 变成**从清单里选**（命中率≈100%）。
    清单 SSoT 在同仓 `src/book2vido/icons.py` 的 `CONCEPTS`
    —— 改词表必须连着图标一起改，否则会出现"新词映射到旧图标"。
-->
【concept 可选清单】
{{concept_list}}

  ↑ {{concept_list}} 由代码注入（icons.CONCEPTS 的键，顿号连接，按语义分组顺序）。

## 改动影响面

| 你改这里 | 会牵动谁 | 怎么察觉 |
|---|---|---|
| 角色句 / 口语化措辞 | 整体文风 | 抽一章看产出 |
| `{{max_n}}` 的取值 | 成片时长 | 改 `config.yaml` 的 `limits.max_sentences` |
| ≤20 字 | 卡片排版（换行） | 跑一章，看卡片是否挤 |
| keyword 规则 | 卡片大标题 | 同上 |
| concept 规则 / 词表 | 图标命中率 | `doc/08-画面资产策略.md` 的去重判据：**12 张卡应出现 12 个不同图形** |
| 示例（few-shot） | 全线上：模型会模仿示例的口气与粒度 | 对照重跑 |
| 任何改动 | 缓存**自动**失效，下次出片重跑模型 | `script.json` 里的 `prompt_version` / `prompt_hash` |

## 验证（改完必跑）

```bash
# ① 渲染结果与 golden 逐字节比对 + 注释是否剥干净 + 占位符是否全替换
python tests/verify_prompt.py

# ② 缓存该失效：同一章连跑两次，第一次必须是 miss（重跑模型），第二次才是 hit
PYTHONPATH=src python -m book2vido run --input <你的素材> --chapter 1 --out /tmp/t.mp4
```

`tests/verify_prompt.py` 会在提示词**有意改动**后报"与 golden 不一致"——那是正常的，
把新渲染结果更新为 golden（脚本里有 `--update`）并说明改了什么即可。
它真正要抓的是**意外改动**：注释剥离不干净、占位符漏替换、改 A 结果 B 也变了。
