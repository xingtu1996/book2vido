# 03 · 零成本画面（核心差异化）

## 角色
把口播稿的每句 / 每段变成「能扫完」的视觉。这是 huobao/ViMax 烧钱的地方（文生视频 + 文生图），我们用**代码生成 + 矢量拼贴**替代，成本≈¥0。

## 四档零成本方案
| 档 | 开源项目 | 许可 | 角色 |
|----|----------|------|------|
| 信息卡 / 干货图 | **AntV Infographic**（蚂蚁, MIT, 6.6k★） | MIT | 文章→数据卡 / 要点卡，中文生态最强 |
| 手绘图表 | **Excalidraw**（MIT）+ **excalidrawer**（CLI/MCP 生成） | MIT | 代码生成可编辑手绘图 |
| 文字→图标 | **TextPrism**（90k 离线图标库） | 开源 | 关键词卡自动配图标 |
| 矢量插画拼贴 | **unDraw**(MIT) / **Humaaans**(CC0) / **Open Peeps**(CC0) | 可商用免署名 | 封面 / 人物拼贴 |

## 默认 MVP 画面策略
- 每句口播配一张 **Pillow 生成的信息卡** + 关键词图标（TextPrism）。
  ⚠️ **配色以 `config.yaml` 的 `visual.theme` 为准**（默认 `ink` 黑红灰；`blue` 即原 `#056DE8` 行途蓝，
  现仅作回退 / A-B 对照）。色板 SSoT 是行途封面设计规则 V1.2「黑红灰」。
- 复杂数据用 AntV Infographic 出图。
- 人物场景用 unDraw / Humaaans 拼贴。
- **不调用任何文生图 API**。
