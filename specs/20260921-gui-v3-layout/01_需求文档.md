# Book2Vido GUI v3 需求文档

## 一、产品定位

**Book2Vido** = 长文/厚书 → 本地模型浓缩精华 → 半分钟竖屏短视频

**目标用户：** 完全不懂技术的同事（如段梦春），双击 .app 就能用，全程零命令行。

**核心价值：**
- 把厚书/长文用本地大模型蒸馏成半分钟短视频
- 不用视频也能问答（本地大模型直接读文档）
- 全本地运行，不联网不上传，隐私安全

## 三、组件逻辑说明

### 1. 品牌区（顶部）
- **内容：** Book2Vido 标题 + slogan（长文/厚书 → 本地模型浓缩精华 → 半分钟竖屏短视频）
- **逻辑：** 纯展示，告诉用户这是什么产品
- **交互：** 无

### 2. 环境状态条（卡片）
- **内容：**
  - Ollama 状态（绿点 Running / 红点未安装）
  - 本地模型（qwen3:8b）状态
  - FFmpeg 状态
  - **上传文件按钮**（右上角，黑色按钮）
- **逻辑：**
  - 页面加载时自动调 `/api/check-env` 检测三个组件
  - 绿点 = 正常，红点 = 未安装/异常
  - **红点旁边显示"一键安装"按钮**（待开发）
  - 上传按钮触发文件选择器（PDF/MD/TXT）
- **交互：**
  - 点击上传按钮 → 打开文件选择对话框
  - 支持拖文件到页面任意位置
  - 点击"一键安装" → 开始安装对应组件

### 3. 进度条（卡片）
- **空状态（未上传文件）：** **整个进度条卡片隐藏**，不显示
- **内容：**
  - 进度百分比条（黑色填充）
  - 当前步骤名（提取文本/写口播稿/配音/合成...）
  - ETA 预计剩余时间
- **逻辑：**
  - 上传完成后自动显示并开始跑进度
  - 每 500ms 轮询 `/api/progress` 接口更新进度
  - 生成完成后进度条停在 100%，3 秒后自动隐藏
  - **错误状态：** 进度条变红，显示错误信息
- **交互：** 无（纯展示）

### 4. 目录卡片（左栏）
- **空状态（未上传文件）：** 显示"📚 上传文件后自动显示目录"灰色提示文字
- **内容：**
  - 章节列表（从 PDF/MD 自动提取）
  - 每个章节显示标题 + 页码范围
  - **生成全书总览按钮**（黑色大按钮）
- **逻辑：**
  - 上传文件后自动提取目录，显示在这里
  - 点击某个章节 → 高亮选中，生成时只生成该章节
  - 不选章节 → 默认生成全书总览
  - "生成全书总览"按钮 → 触发生成 pipeline
- **交互：**
  - 点击章节 → 选中/取消选中
  - 点击"生成全书总览" → 开始生成

### 5. 视频播放卡片（中栏）
- **空状态（未生成视频）：** 显示"🎬 上传文件后，视频会在这里播放"占位文字
- **尺寸：** 竖屏 9:16 比例，最小宽度 300px，自适应填充
- **内容：**
  - 黑色视频区域
  - 生成过程中显示"正在生成..."动画
  - 生成完成后自动播放
  - 右上角 × 关闭按钮
- **逻辑：**
  - 上传文件后初始显示占位
  - 生成过程中显示加载动画
  - 生成完成后自动加载并播放视频
- **交互：**
  - 点击视频 → 暂停/播放
  - 点击 × → 关闭视频，回到占位状态

### 6. 历史输出卡片（右栏）
- **空状态（第一次使用）：** 显示"还没有生成过视频，上传文件试试吧～"灰色提示
- **内容：**
  - 历史视频列表（名称 + 日期 + 大小 + 播放按钮）
  - "打开文件夹"按钮（打开输出目录）
- **逻辑：**
  - 页面加载时调 `/api/history` 获取历史视频列表
  - 每次生成完成后自动刷新列表
- **交互：**
  - 点击历史视频 → 在中间视频区域播放
  - 点击"打开文件夹" → 在 Finder 中打开输出目录

### 7. 聊天区（底部全宽卡片）
- **空状态（未上传文件）：** 聊天区整体禁用，输入框灰掉，显示"请先上传文件，我才能和你聊这本书～"
- **内容：**
  - 聊天气泡区（用户消息靠右黑色，AI 消息靠左白色）
  - **性能指标面板**（每条 AI 回复下面显示一行小指标）
  - 输入框 + 发送按钮 + 停止按钮
  - 快捷提问按钮（这本书讲了啥 / 核心观点 / 总结重点）
- **性能指标白盒化（参考 ollama_webui.html）：**
  - ⚡ **解码速度 TPS**：tok/s
  - ⏱️ **首字延迟 TTFT**：秒
  - 📝 **输出 token**：数量
  - 📊 **输入 token**：数量
  - ⏳ **总耗时**：秒
- **逻辑：**
  - 上传文件后自动提取全文（前 2 万字）存到 `_current_doc`
  - **聊天记录存 localStorage**，刷新页面不丢
  - 支持多轮对话（带历史上下文）
  - 用户输入问题 → 调 `/api/chat` 接口
  - 后端调 Ollama `/api/chat`，透传完整性能指标
  - **意图识别：** 如果用户说"做视频/生成视频/转成视频"，自动触发生成 pipeline
    - 如果用户说"把第三章做成视频" → 自动选中第三章，再触发生成
- **交互：**
  - 输入文字 → 按回车或点发送
  - 点击快捷按钮 → 自动填充问题并发送
  - 生成中 → 显示停止按钮，点了可以中止
- **错误状态：** 聊天失败时显示"网络错误，请稍后重试"

## 四、用户旅程（User Journey）

### 场景一：首次使用（新用户）

```
1. 双击 Book2Vido.app
   ↓
2. 打开浏览器，看到主界面
   ↓
   「这是啥？哦哦，把厚书变成短视频」
   ↓
3. 环境检查：三个绿点都亮了（Ollama/模型/FFmpeg）
   ↓
   「环境都好了，可以直接用」
   ↓
   （如果有红点 → 显示"一键安装"按钮，点击安装）
   ↓
4. 点击右上角"上传文件"按钮
   ↓
5. 选择一个 PDF（比如《关键对话》）
   ↓
6. 进度条卡片出现：正在提取文本...
   ↓
7. 目录卡片自动出现：第一章/第二章/第三章...
   ↓
8. 用户想直接生成全书总览，点击"生成全书总览 →"
   ↓
9. 进度条更新：正在写口播稿... 剩 1:20
   ↓
10. 进度条继续：正在配音... 正在合成...
    ↓
11. 中间视频卡片自动播放生成的视频
    ↓
12. 用户看完视频，觉得不错
    ↓
13. 在底部聊天区问："这本书核心观点是啥？"
    ↓
14. AI 自动总结核心观点
    ↓
15. 用户说："把第三章也做成视频"
    ↓
16. 意图识别：自动选中第三章，开始生成新视频
    ↓
17. 完成！视频出现在中间播放，历史输出里也多了一条
```

### 场景二：老用户继续使用

```
1. 双击 Book2Vido.app
   ↓
2. 打开浏览器，看到主界面
   ↓
3. 历史输出里有上次生成的视频
   ↓
4. 聊天记录还在（localStorage 存的）
   ↓
5. 点击历史视频，中间区域直接播放
   ↓
6. 或者上传新文件，开始新的生成
```

### 场景三：环境未就绪（第一次装）

```
1. 双击 Book2Vido.app
   ↓
2. 环境检查：Ollama 红/模型红/FFmpeg 红
   ↓
3. 每个红点旁边显示"一键安装"按钮
   ↓
4. 用户点击安装，显示安装进度
   ↓
5. 安装完成后，三个绿点都亮了
   ↓
6. 正常使用
```

### 场景四：出错了怎么办

```
1. 上传失败 → 显示红色 toast："上传失败，请检查文件格式"
2. 生成失败 → 进度条变红，显示错误信息："生成失败：FFmpeg 未安装"
3. 聊天失败 → 显示红色 toast："网络错误，请稍后重试"
```

## 六、技术架构

### 前端
- 单页应用：index.html + style.css + app.js
- 零依赖，纯 HTML/CSS/JS
- 模块化组件：目录/视频/历史/聊天
- 聊天记录存 localStorage

### 后端
- Python 内置 ThreadingHTTPServer
- 接口：
  - `GET /api/check-env` — 环境检查
  - `POST /api/upload` — 上传文件
  - `POST /api/run` — 开始生成
  - `GET /api/progress` — 获取进度
  - `GET /api/history` — 历史列表
  - `GET /api/video/<name>` — 播放视频
  - `POST /api/chat` — 聊天问答（带对话历史）
  - `GET /api/open-folder` — 打开输出目录

### 数据流
```
上传文件 → extractor 提文本 → outline 提目录 → scriptwriter 写口播稿
→ narrator 配音 → visualizer 画信息卡 → compositor FFmpeg 合成
→ 输出到 ~/Movies/Book2Vido/
```
