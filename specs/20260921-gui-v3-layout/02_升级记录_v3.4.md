# Book2Vido GUI v3.4 升级记录 — 进度可视化 + 中文友好 + 流式聊天

> 日期：2026-09-21
> 工具：doubao
> 版本：v3.3 → v3.4

## 一、本次改了什么

### 1. 进度可视化（老板痛点：一直显示"准备中"不知道在干嘛）

**之前**：进度条只显示"准备中..."三个字，用户完全不知道在干什么。

**现在**：
- 每一步都有中文标签：`第 1/6 步 · 加载配置`、`第 2/6 步 · 解析文档目录`、`第 3/6 步 · AI 生成全书总览文案`
- 进度条黑色填充，实时移动
- 右侧显示 `已用 Xs / 剩 Ys`（ETA 估算）

**6 个步骤及预计耗时**：

| 步骤 | 中文标签 | 预计耗时 |
|---|---|---|
| 1 | 加载配置 | 2s |
| 2 | 解析文档目录 | 3s |
| 3 | AI 生成全书总览文案 | 60s（最慢） |
| 4 | 配音合成 | 20s |
| 5 | 渲染视频 | 15s |
| 6 | 完成 | 1s |

### 2. 流式聊天（打字机效果）

- 后端 `/api/chat` 改成 SSE 流式接口
- 前端 `fetch().body.getReader()` 边接收边显示
- 每条 AI 回复下面显示性能面板：耗时 / TPS / tokens

### 3. 修了两个 bug

| Bug | 原因 | 修复 |
|---|---|---|
| `/api/run` 一调用就崩（Empty reply） | 函数内 `import time` 导致 Python 把整个函数的 `time` 当局部变量 | 删掉函数内重复 import，用顶部全局 import |
| 后台线程 `NameError: Path` | 拆分 `tasks.py` 时丢了 import（B-048 坏例复现） | 补全 `Path`/`threading`/`pipeline`/`load`/`project_root` |

### 4. 前后端字段对齐

| 之前（错） | 现在（对） |
|---|---|
| 前端调 `/api/progress` | 后端是 `/api/status?job_id=xxx` |
| 前端要 `step`/`percent` | 后端给 `message`/`progress` |
| done 后找 `data.video` | 从 `data.results[0].url` 取 |
| `/api/run` 没传 path | 传 `path` + `chapters` |
