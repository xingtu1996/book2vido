# book2vido GUI v2 · 总纲

> 日期：2026-09-21
> 目标：从"命令行跑通"升级到"同事双击即用"的完整 GUI 产品闭环

---

## 一、需求来源

### 1.1 同事反馈（段梦春，微信群聊 2026-09-15）
- "不用视频，你也能问答。这就是最屌的地方，他直接给你转了 1 个本地大模型。"
- "能不能多次扔内容进去然后提问？"
- "感觉这个产品做出来还能卖钱，上架 app store"
- 提出方向：老年陪伴（长期，本次不做）

### 1.2 Boss 需求（2026-09-21）
- 先进界面，再引导安装（不要卡前置检查）
- 每个依赖（Ollama/模型/FFmpeg）一个卡片，缺了就点安装
- 实时进度条 + 日志滚动（像在线视频加载）
- 上传 PDF → 识别目录 → 推荐一键生成总览
- 看完能对着书提问（RAG 问答）

## 二、功能分解（三档优先级）

### P0 · 必做（保证同事能跑通）
| 功能 | 描述 | 工作量 |
|------|------|--------|
| **F1. 首屏环境仪表盘** | 三个卡片：Ollama / 本地模型 / FFmpeg，各自显示状态（✅/❌/⚠️），缺了就显示「安装」按钮 | 2h |
| **F2. GUI 化安装触发** | 点击按钮 → 后台跑安装命令 → 实时输出日志 → 完成后自动刷新状态 | 3h |
| **F3. 实时进度+日志面板** | 生成过程中，下方滚动日志流 + 顶部进度条，像看视频加载一样 | 2h |

### P1 · 应做（提升体验）
| 功能 | 描述 | 工作量 |
|------|------|--------|
| **F4. 目录识别+一键总览** | 上传后自动提取目录，显示章节列表，加个「生成全书总览」推荐按钮 | 1h |
| **F5. 输出历史列表** | 之前生成的视频列出来，点了就能看，不用重新跑 | 2h |

### P2 · 可选（第二版再加）
| 功能 | 描述 | 工作量 |
|------|------|--------|
| **F6. RAG 书问答** | 上传 PDF 后自动建索引，加个「聊天」Tab，能对着书提问 | 2-3天 |

## 三、任务依赖 DAG

```
G0 · 准备工作（无依赖）
├── T1. 后端 API 设计（环境检查/安装触发/日志流）
├── T2. 前端 UI 框架改造（从单步流程 → 多 Tab 仪表盘）
└── T3. 现有代码梳理（server.py / index.html 现状盘点）

G1 · 并行开发（依赖 G0）
├── 🔵 分支A：后端 API 层
│   ├── T4. /api/install/<component> 安装触发接口
│   ├── T5. /api/logs 实时日志流（SSE 或轮询）
│   └── T6. /api/history 历史输出列表
│
├── 🔵 分支B：前端 UI 层
│   ├── T7. 环境仪表盘组件（三卡片 + 安装按钮）
│   ├── T8. 生成进度面板（进度条 + 滚动日志）
│   └── T9. 输出历史列表组件
│
└── 🔵 分支C：核心流程优化
    ├── T10. 目录识别 + 一键总览按钮
    └── T11. 上传后自动跳转目录选择

G2 · 集成测试（依赖 G1）
├── T12. 前后端联调（安装流程端到端）
├── T13. 生成流程端到端测试
└── T14. 打 .dmg 安装包
```

## 四、并行执行计划

| 波次 | 任务 | 执行方 | 预计耗时 |
|------|------|--------|----------|
| **Wave 1** | T1+T2+T3（设计+梳理） | 主会话 | 30min |
| **Wave 2** | T4+T5+T6（后端 API）<br>T7+T8+T9（前端 UI）<br>T10+T11（核心流程） | 三个并行子任务 | 4h |
| **Wave 3** | T12+T13（联调测试） | 主会话 | 1h |
| **Wave 4** | T14（打 dmg） | 主会话 | 30min |

## 五、验收标准

- [ ] 双击 .app 直接进界面，不卡前置检查
- [ ] 缺哪个依赖，界面上就显示哪个的「安装」按钮
- [ ] 点安装按钮后能看到实时日志，装完自动变绿
- [ ] 生成过程有进度条 + 滚动日志，能看到每一步在干啥
- [ ] 上传 PDF 后能看到目录，能一键生成全书总览
- [ ] 生成完的视频列在历史里，点了就能看

---

## 六、边界与红线

- 全程本地运行，不联网不上传
- 不引入新的大依赖（保持零依赖或仅用标准库）
- 品牌色对齐：黑红白 + 行途蓝 #056DE8
- 代码注释用英文（对外开源友好）
