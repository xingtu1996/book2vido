## 范围

**IN**：PDF 目录树提取（outline 优先 / 正则兜底）→ `outline.json`；章节级切分（按页码，替换 `[:2500]`）；
CLI `outline`/`list`/`run --chapter N`/`--chapters 1,3,5`/`--all`；TTS 并发（重试 + 自适应降并发）；
三层缓存 + `script.json` 人工可改；跨模块契约统一进 `models.py`。

**OUT（连同理由）**

| 不做 | 理由 |
|---|---|
| 网页「点播」界面（P5） | CLI 未稳前先套界面＝提前支付维护成本（宪法铁律四） |
| 章级流水线（A 章配音时 B 章推模型） | TTS 并发后剩余收益仅 8%，不划算 |
| 并行 LLM 请求 | 实测 Ollama 服务端串行，省 5%＝噪声（`doc/10` 探针 2） |
| LangChain / Celery / Prefect / Ray | 按长度切分器不懂章节语义；给「12 句视频」上分布式调度是负收益 |
| 文件监听「热加载」 | 本项目是批处理 CLI，进程起→出片→退出，无常驻服务可热替换（见 `01_analysis` §四） |
| 向量检索 / RAG 选段 | 先解决结构，再谈语义 |
