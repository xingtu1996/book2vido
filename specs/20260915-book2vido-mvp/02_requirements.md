# 02 · Requirements（验收标准 AC）

## 功能 AC
- **AC1** 输入 PDF/MD/长文（路径），输出 mp4 到指定目录。
- **AC2** 抽取：文本型 PDF 用 pypdf；MD/长文直读；无需 OCR 的样本零成本。
- **AC3** 口播稿：本地 Ollama Qwen3-8B 生成口播稿 + 分镜；**provider 可插拔**，无 Ollama 时降级为「规则截取前 N 句」保证端到端先跑通。
- **AC4** 画面：每句/段配信息卡（Pillow + 行途蓝 #056DE8，复用 P028 规范）+ 关键词图标；**不调用任何文生图 API**。
- **AC5** 配音：edge-tts 默认；可切 macOS say 本地；TTS provider 可插拔。
- **AC6** 合成：FFmpeg 拼信息卡序列 + 语音轨 → 竖版 1080×1920 mp4。

## 质量 / 成本 AC
- **AC7** 单条 1min 成本≈¥0（仅电费），成本日志可打印。
- **AC8** 全程不调用任何公司订阅 key/API（合规铁律一）。
- **AC9** 断网可跑（TTS 切 say 时）。
- **AC10** 视觉质量目标＝「能知道文章内容」，不追求高画质。

## 批量 AC
- **AC11** 支持目录批量：存量书/素材一键盘活。

## 非目标（本期不做）

- 小程序壳 / 自助工具
- 自动发布（UI-TARS 留接口，不实现）
